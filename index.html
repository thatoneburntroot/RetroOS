HOW TO USE
-----------

• Double-click desktop icons to open applications.

• Drag a window using its blue title bar.

• Use "_" to minimize a window.

• Use "□" to maximize a window.

• Use "X" to close a window.

• Click a taskbar button to restore
  or focus a window.

• Click START to open the Start Menu.

• Use the volume slider on the taskbar.

• Click the power icon to turn the
  computer screen off.

• Click the black screen to turn
  the computer back on.

• The Internet application intentionally
  reports websites as unavailable.

• RetroIDE allows you to edit HTML.

• Press RUN in RetroIDE to preview
  your code in a new browser tab.

• Press SAVE to save your code
  in the browser's local storage.
