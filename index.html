RETROOS README

==============================

WELCOME TO RETROOS

A simple old-school computer
operating system built entirely
with HTML, CSS and JavaScript.

==============================

HOW TO USE

Double-click a desktop icon
to open an application.

Drag windows by their title bar.

_ = Minimize

□ = Maximize

X = Close

Use the taskbar to switch
between open applications.

Click START to open the
RetroOS Start Menu.

Use the volume slider on the
right side of the taskbar.

Click the power button to
turn the computer off.

Click the black screen to
turn it back on.

==============================

APPLICATIONS

🌐 Internet
Shows websites as unavailable.

📝 Notepad
A simple text editor.

📁 My Computer
Displays the RetroOS file system.

💻 RetroIDE
Write and preview HTML.

📄 README
This document.

==============================

RETROIDE

Write HTML inside the editor.

Press RUN to open your
website in a new browser tab.

Press SAVE to store your
code in local storage.

==============================
